# VAGPR A 股涨跌幅预测器

本地双输出加性高斯过程研究工具，默认合锻智能（上交所 603011），支持切换沪深股票。Windows x64 便携版无需安装 Python，双击 `VAGPR-Return.exe`，点击「更新行情」即可运行。也可离线导入本地 CSV。程序不需要账号、API 密钥或后台服务器。

## 运行

- 「更新行情」：获取约 500 根日线（优先腾讯，东方财富备用），默认预测未来 5 根有效日线后的终点，同时显示历史滚动回测。
- 主输出是相对最近收盘的 **1、5 或 10 个交易日累计绝对涨跌幅**，不是行业超额收益或逐日预测。原始 VAGPR 估计与校正值分开。若历史校正选择零权重，0% 表示使用不变基准，不是预计价格必然不动。
- 日线图显示实际交易日期和收盘价，支持 30/60/120/250 日、后复权/未复权切换及鼠标悬停查价。切换图表复权口径不改变模型，模型始终用后复权数据。
- 「导入 CSV」：使用导出的行情，或同格式的自备数据。表头为 `date,open,close,high,low,volume,raw_close`；日期为 `YYYY-MM-DD`，严格递增，至少 220 条；OHLC 必须是同一后复权口径，`raw_close` 为未复权收盘。CSV 本身无法验证是否遗漏交易日、个股代码或复权口径。
- 「导出报告」写 JSON。量化结果只用于研究，不是买卖建议。公开仓库不分发行情原始数据或论文稿件。

源码运行（Python 3.12 x64）：

```powershell
python -m pip install -r requirements.txt
python vagpr.py
python vagpr.py --fetch --horizon 5 --save-csv daily.csv --report forecast.json
python vagpr.py --fetch --symbol 600000
python vagpr.py --csv daily.csv --report offline.json
python scan.py --report scan.json
python -m unittest -v
```

## Windows 打包

在 Windows x64、Python 3.12 环境中：

```powershell
python -m pip install -r requirements-build.txt
.\build.ps1
```

脚本会运行单元测试、生成 `dist/VAGPR-Return.exe`、用合成数据做离线打包测试，并输出 SHA-256。无需真实行情、Wind 或私有 API 密钥即可执行测试。

## 沪深 300 批量筛选

批量筛选由 `scan.py` 执行：用中证指数成分表限定沪深 300 范围，从腾讯行情取滚动市盈率 TTM（快照字段 39），要求 `0 < TTM < 20`，并核对快照和日线的日期及收盘价。正点估计不等于通过回测，输出同时保留区间、基准比较和覆盖率。今天的估值过滤不代表历史可投资组合；逐股回测并非验证今日候选筛选策略，也没有校正多重比较。

## 从论文到个股

论文 §2 提出了矩阵值核、正交加性结构和多任务预测；§3 用 2000–2024 年的 Wind 数据联合预测上证指数收盘价和投资者情绪指数。本文档中的个股程序是**方法迁移版，不是论文实证复刻**。论文使用的 Wind 情绪序列、八项输入的逐日可用时点、完整训练/检验切分、两月预测时的未来协变量处理、热核参数及跨任务参数未随代码提供，因此不声称重现论文表 2 的误差。

1. **任务**：目标一为未来 `h` 根有效日线的累计后复权对数收益；目标二为同段日对数收益的 RMS 的对数。波动率不是情绪代理。预测的是终点和整段波动，不是逐日路径。
2. **输入**：截至预测起点可知的 1/5/20 日收益、20 日 RMS、日内振幅、成交量相对滞后 20 日中位数的对数比。数据按中国时间收盘后留出 15 分钟缓冲；交叉检查后复权、未复权日线和最新快照。未接入交易所日历，异常停牌或漏报要另行检查。
3. **核与估计**：使用标准正态参考分布下零积分平方指数核（论文式 25），以及一阶主效应、二阶成对 Hadamard 乘积。每阶各配一个正定的 2×2 任务协方差矩阵。长度尺度固定为 1.25；两阶幅度、任务相关性和标准化后共享观测噪声通过边际似然拟合。式 23 印刷的加号与条件高斯协方差及式 25 不一致，本实现用减号。区间从联合核的标准条件高斯公式计算，包含观测噪声；没有独立相加各分量的后验方差。
4. **边界**：当前没有可定义流形的输入，未实现热核，也不输出 Sobol 排名；成交量和收益等特征之间的相关性不应解读为因果归因。未复权参考价以最后一日未复权收盘乘上预测涨跌幅得到，除权除息时不等同于未来实际报价。
5. **回测与校正**：每个测试起点向后预测 `h` 根有效日线，起点间隔 `h`，最多 80 次。GP 最多用 150 个已实现目标的历史样本，标准化只用当期训练窗口；每六个测试起点重估核超参数。校正用此前 20 至 40 个已结束的样本外预测，以简单收益 MAE 从 `{0, 0.25, 0.5, 0.75, 1}` 选权重，乘在 VAGPR 的对数收益估计上。区间用此前实际发出的校正估计的标准化残差分位数确定，80% 是目标而不是保证。前 20 个起点用作预热，不计入主模型、原始模型和不变基准的同段误差比较。筛查还要求至少 30 次非零方向预测，并在收益 MAE、RMSE 和方向上胜过对应对照；这不是显著性检验。按收盘才能得到的特征回测，也不代表可按同一收盘价成交。

后复权行情可能被供应商回填或修订。此检验使用一个最新历史快照，避免标签跨越预测起点，但不是保存过的逐日原始点时间数据。高波动和结构变化可能使模型区间偏窄，应并看实际覆盖率和预测误差。
